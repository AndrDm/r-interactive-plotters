# Примеры интерактивных графиков

## 🚀 Быстрый старт

```bash
# Установка зависимостей Ubuntu
sudo apt update
sudo apt install build-essential pkg-config libgtk-3-dev libx11-dev

# Запуск главного меню лаунчера (рекомендуется)
cargo run

# Или прямой запуск отдельных примеров
cargo run --bin basic_interactive          # Базовое рисование линий
cargo run --bin advanced_annotations       # Продвинутые аннотации
cargo run --bin interactive_measurements   # Измерения и crosshair
cargo run --bin coordinate_system          # Система координат
```

## 📋 Демонстрируемые возможности

### 1. basic_interactive.rs
**✅ Решает основную задачу: рисование линий поверх графика с автоматическим масштабированием**

**Что демонстрирует:**
- ✅ Рисование произвольных линий в координатах графика
- ✅ Автоматическое масштабирование всех элементов при zoom/pan
- ✅ Crosshair в режиме рисования
- ✅ Переключение между режимами навигации и рисования
- ✅ Завершение линий правым кликом мыши

**Управление:**
- Включите чекбокс "Режим рисования"
- ЛКМ - добавить точку к текущей линии
- ПКМ - завершить текущую линию
- Колесо мыши - масштабирование
- Перетаскивание - панорамирование графика

### 2. advanced_annotations.rs
**✅ Полнофункциональная система аннотаций**

**Что демонстрирует:**
- ✅ Вертикальные и горизонтальные указатели с метками
- ✅ Текстовые аннотации с автонумерацией
- ✅ Выделение прямоугольных областей
- ✅ Предпросмотр элементов в реальном времени
- ✅ Переключение между 5 режимами работы

**Режимы:**
- 📋 Навигация - обычное перемещение по графику
- 📏 Вертикаль - добавление вертикальных пунктирных линий
- 📐 Горизонталь - добавление горизонтальных пунктирных линий
- 📝 Текст - добавление текстовых аннотаций с координатами
- 🔲 Область - выделение прямоугольных областей (клик-клик или клик-перетащить)

### 3. interactive_measurements.rs
**✅ Профессиональная система измерений**

**Что демонстрирует:**
- ✅ Crosshair с отображением координат в реальном времени
- ✅ Измерительная линейка с расчетом расстояний
- ✅ Snap к точкам данных (магнитная привязка)
- ✅ История всех измерений
- ✅ Настраиваемые параметры snap

**Особенности:**
- 🎯 Crosshair следует за курсором и показывает точные координаты
- 📏 Двухточечные измерения: клик-клик для определения расстояния
- 🧲 Автоматическая привязка к ближайшим точкам данных (настраиваемый радиус)
- 📊 Каждое измерение показывает: расстояние, dx, dy
- 🔒 Опция блокировки соотношения сторон графика

### 4. coordinate_system.rs
**✅ Подробная демонстрация системы координат**

**Что демонстрирует:**
- ✅ Преобразование между экранными и графическими координатами
- ✅ Отслеживание всех типов событий мыши
- ✅ Интерактивная сетка координат
- ✅ Перетаскиваемые демонстрационные точки
- ✅ Подробная информация о трансформациях

**Интерактивные элементы:**
- 🔄 Демонстрационные точки с координатами в обеих системах
- 💎 Золотая перетаскиваемая точка
- 📐 Адаптивная сетка координат
- 📋 История событий мыши (клики, перетаскивание, прокрутка)
- 🔍 Информация о масштабе и границах графика

## 🎯 Ключевые архитектурные принципы

### Автоматическое масштабирование
Все элементы рисуются в **координатах графика**, поэтому автоматически масштабируются:
```rust
// Линия остается в тех же позициях относительно данных
let line = Line::new(PlotPoints::from(vec![[x1, y1], [x2, y2]]))
    .color(egui::Color32::RED);
plot_ui.line(line);
```

### Получение координат мыши
```rust
if let Some(plot_pos) = plot_ui.pointer_coordinate() {
    // plot_pos автоматически в координатах графика!
    println!("Мышь в позиции данных: ({:.2}, {:.2})", plot_pos.x, plot_pos.y);
}
```

### Обработка событий
```rust
if plot_ui.response().clicked() {
    // Обработка клика в координатах данных
    user_lines.push(plot_pos);
}
```

## 🏆 Заключение

**egui_plot** предоставляет все необходимое для создания профессиональных интерактивных графиков с возможностью рисования поверх данных. Ключевое преимущество - автоматическое масштабирование всех элементов при изменении масштаба графика, что решает основную задачу интерактивной визуализации данных.

Все примеры готовы к использованию в production и демонстрируют лучшие практики разработки интерактивных приложений в Rust.
